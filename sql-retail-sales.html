Retail Sales Analysis

End-to-end SQL practice project focused on exploring retail transaction data, calculating sales KPIs, and identifying category, product, customer, and monthly sales trends.

Project objectives

  • Explore and validate retail transaction data.
  • Calculate gross sales, discounts, net sales, and average sale value.
  • Analyse sales by category, product, customer, and month.
  • Use SQL aggregation, grouping, sorting, date functions, and analytical queries.
  • Present findings through tables and charts.

Tools

Oracle SQL, CSV dataset, HTML, data analysis and visualisation.

Dataset

150 synthetic practice transactions covering 2025, with customer, product, quantity, unit price, and discount fields.

Data transparency

This project uses synthetic data created for practice and portfolio demonstration. It does not represent a real company, real customers, or actual commercial performance. The results page reports calculations from this dataset only.
