Sample SQL query templates

The examples below use a planned table structure. Column and table names will be adjusted to match the final dataset before execution.

1. Total sales

SELECT
    SUM(quantity * unit_price) AS total_sales
FROM retail_sales;

2. Sales by product category

SELECT
    category,
    SUM(quantity * unit_price) AS category_sales
FROM retail_sales
GROUP BY category
ORDER BY category_sales DESC;

3. Top 10 products by sales

SELECT
    product_name,
    SUM(quantity * unit_price) AS total_sales
FROM retail_sales
GROUP BY product_name
ORDER BY total_sales DESC
FETCH FIRST 10 ROWS ONLY;

4. Monthly sales trend

SELECT
    EXTRACT(YEAR FROM sale_date) AS sales_year,
    EXTRACT(MONTH FROM sale_date) AS sales_month,
    SUM(quantity * unit_price) AS monthly_sales
FROM retail_sales
GROUP BY
    EXTRACT(YEAR FROM sale_date),
    EXTRACT(MONTH FROM sale_date)
ORDER BY sales_year, sales_month;
These are starter query templates, not claimed project results. Final queries and verified outputs will be published after the dataset is selected and the SQL is executed.
