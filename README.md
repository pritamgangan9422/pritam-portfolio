# Retail Sales Analysis using SQL

## Project status
Starter project prepared. SQL results and business insights must be generated by running the queries against the supplied data.

## Files
- `retail_sales.csv` — 150 synthetic practice transactions.
- `retail_sales_analysis_oracle.sql` — Oracle SQL table definition and 10 analysis queries.

## Dataset note
This is synthetic learning data created for this portfolio project. It is not actual company or customer data.

## Table columns
sale_id, sale_date, customer_id, customer_name, product_id, product_name, category, quantity, unit_price, discount_percent

## Revenue formula
`quantity * unit_price * (1 - discount_percent / 100)`

## Suggested workflow
1. Create the `retail_sales` table using the SQL script.
2. Import `retail_sales.csv` into the table, matching the column order.
3. Run the queries in `retail_sales_analysis_oracle.sql`.
4. Save query outputs/screenshots.
5. Add verified results and insights to the portfolio page.

## Tools
Oracle SQL / SQL Developer (or adapt the script for another SQL database).
